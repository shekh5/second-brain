## Open-Source Infrastructure as Code

OpenTofu is a community-driven infrastructure as code tool under the Linux Foundation's stewardship. It is described as a "drop-in replacement for Terraform." The page cites an ecosystem of 3,900+ providers and 23,600+ modules.

### Examples

- **Create an S3 bucket:** Define an AWS S3 bucket in a few lines of configuration.
- **Configure DNS records:** Manage Cloudflare DNS records as version-controlled code and deploy them with one command.
- **Set up GitHub repositories:** Create repositories, configure branch protection, and manage team access in code.

## Features Unique to OpenTofu

- **Exclusion flag (v1.9):** The `-exclude` flag skips specific resources during `plan` or `apply`, which helps with testing and staged rollouts.
- **Provider iteration with `for_each` (v1.9):** Generate provider configurations dynamically, for example one per region, to reduce repetitive code.
- **Early variable/local evaluation (v1.8):** Variables and locals can be used in module sources and versions, so a single change can update many modules.
- **State encryption (v1.7):** Client-side encryption of state at rest, with key providers including PBKDF2, AWS KMS, GCP KMS, and OpenBao.

## Join Our Community

OpenTofu relies on community contributions. Ways to get involved: GitHub discussions, opening issues for bugs or feature suggestions, RFC discussions and reviews, and contributing code after community discussion. Links are provided for Slack and the contributing guide.

## Frequently Asked Questions

**Why was OpenTofu created?**
It was started by Gruntwork, Spacelift, Harness, env0, Scalr, and others in response to HashiCorp's move from an open-source license to the Business Source License (BUSL). The page states that the license terms were ambiguous and that the project should remain open source.

**Why use OpenTofu instead of Terraform?**
- **Personal use:** Either tool works, but the license situation could change.
- **Consultants:** OpenTofu is positioned as an open-source option with a large contributor base.
- **Companies:** Switching carries risk, but the Linux Foundation stewardship and feature-parity goal reduce it.

**Will OpenTofu be compatible with future Terraform releases?**
The community decides which features OpenTofu gets. Users can request missing features by opening an issue.

**Where can I find providers and modules?**
The OpenTofu Registry at search.opentofu.org hosts compatible providers and modules.
